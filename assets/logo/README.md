# ChatClaudeAgent（CCA）1.0 圖標

標誌由兩個相向的 C 銜接而成，對應工作交接。輪廓採 32 單位格線與 45 度切角，和桌面介面的切角板一致。CCA 本身使用單色；Claude、GPT 等代理的顏色留在各自的名稱、頭像與狀態上。

| 檔案 | 用途 |
| --- | --- |
| `cca-mark.svg`／`.png` | 淺色標誌、透明背景，用於深色底 |
| `cca-mark-dark.svg` | 深色標誌，用於淺色底 |
| `cca-wordmark.svg`／`.png` | 標誌與自繪 CCA 字樣，深色版本 |
| `cca-wordmark-light.svg`／`.png` | 同一組字標的淺色版本 |
| `cca-app.svg`／`.png` | 石墨灰切角底板；PNG 為 1024 × 1024 |
| `cca-app-*.png` | 16 至 256 像素的各尺寸輸出，對應 ICO 內的 15 張圖 |
| `cca-terminal-preview.png` | 16 × 16 點陣的放大示意；實際 CLI 使用半格字元，佔 16 欄、8 列 |

標誌使用 `#E9EDF1`，深色版使用 `#0C0E11`，程式圖標底板使用 `#13161A`。介面內的 SVG 繼承 `currentColor`。不加入漸層、光暈、陰影或第三方標誌。

```powershell
# 由不公開的圖標產生器重建
```

產生器不公開。它同時輸出：

- `assets/cca.ico`：16、20、24、30、32、36、40、48、60、64、72、80、96、128、256 像素，桌面版及 CLI EXE 共用。
- `ui/logo.svg`、`ui/logo.png`：登入頁圖標；SVG 為實際使用版本，PNG 保留給點陣用途。
- `ui/icons.js` 的 `logo`：標題列、伺服器列與系統訊息使用的同一輪廓。
- `src/logo_art.hpp`：由同一母版取樣的 CLI 點陣。

四周至少留出 4 單位空間。不要拉伸、旋轉、套用代理配色或將兩個 C 分開。小尺寸採實際輸出，不用 1024 像素 PNG 強制縮放作為交付檔。

設計參考、採用理由及驗證方法見 [1.0 設計紀錄](../../docs/brand-1.0.md)。

另有預備用途的 社群開發者圖標，屬於獨立角色識別資產，目前沒有啟用對應功能。
