# CCA 個人徽章資產

七款圖形由不公開的圖標產生器重建，不需第三方套件。

- 無尾碼 SVG：24 像素母版。
- `-16.svg`：16 像素專用母版，放大留白並簡化銜接。
- `-mono.svg`／`-mono-16.svg`：繼承 `currentColor` 的單色版本。
- `ui/badge_icons.js`：由相同母版產生的靜態內嵌 SVG，顏色使用介面的 `--badge-*` 變數。

不包含字體、漸層、光暈、外部圖片或第三方徽章。原初、熟識、今時三款參考本機歷代 EXE，但使用重新繪製的徽章輪廓。

目錄順序為：CCA 開發者、社群開發者、CCA 原初、CCA 熟識、CCA 今時、先鋒支持者、成員。使用者可自行調整展示順序與隱藏；完整持有清單不受影響。設計及操作見 [個人徽章](../../docs/badges.md)。
