# Gemini 介面與角色整合驗證（1.0.1-）

日期：2026-10-27。此輪未提交或推送。既有未提交變更保留。

## 實際變更

- Gemini 有獨立的原生訊息、思考與規範重試位置，不再占用 GPT 的狀態。停止時結束 Gemini 的回合並保存任務狀態。
- 個人資料支援 Gemini 名稱、裁切頭像、橫幅、日期、資料卡與性格。性格格式、儲存、指派、刪除及 CLI 選單均接受 Gemini；測試核對實際子程序 stdin 包含選定提示詞。
- 流程以持久節點 ID、設定順序與目前游標顯示，多個 Gemini 節點保留各自狀態。桌面每列最多三個節點，CLI 依序顯示，空間不足時保留目前節點摘要。API／本地工作程序的橋接狀態也轉回實際後端名稱。
- 成員、訊息和交接並列節點別名與目前個人名稱。資料卡可進入編輯；參與帳號的額度一起顯示。
- 自動模型頁只列流程中支援的 Claude／GPT 節點，另說明 Gemini 使用 CLI 預設模型；沒有模型目錄時不猜模型或思考程度。
- 本機性格檔可明確設定 assignOnFirstUse，只套用沒有指派欄位的代理，不覆蓋 none、既有性格或名稱。發行包不含角色資料。
