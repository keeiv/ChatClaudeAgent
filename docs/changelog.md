# 更新紀錄

1.0.2-oss 新增 Haiku 手機模擬：軟體更新頁的 Android 安裝包可以「在電腦上以手機模擬開啟」，CCA 開一個手機大小的視窗，載入未修改的 Haiku APK 並扮演它的 Android 殼層；視窗上標明「你已經有桌面版了，建議使用桌面版」。[說明與限制](phone-simulator.md)。1.0.2- 重做更新視窗並加入自動除錯：兩個 C 形筆畫隨更新階段靠攏、鎖定，完成時打勾、失敗時變紅，下方步驟條標出目前在哪一步；更新程式會先預檢目錄權限與磁碟空間、清掉上次留下的殘檔、在檔案被防毒軟體或檔案總管暫時占用時自動重試，失敗時用一句話說明原因（新版結束碼、被占用的檔案等），並留下 `result.json` 與 `update.log`。[操作與復原](workbench.md)。

1.0.1-astra 開放 CCA 插件：一份 `plugin.json` 就能加入介面主題、對話模式與輸入框指令；插件只有資料，啟用前列出全部內容，檔案改動即停用。[格式與安全界線](plugins.md)。1.0.1-sol 新增兩道防線與三款主題：群組可設定一行測試指令，審查者改了檔案後由 CCA 實際執行；測試轉紅而審查前是綠的，就還原審查者的修改並把失敗輸出交給下一位。API 代理的 MCP 工具會釘住核准時的描述雜湊，伺服器事後改動描述就被阻擋。主題新增 2026 萬聖節（亮、暗）與追獵行動。[設計與限制](reviewer-guard.md)。1.0.1-terra 開啟版本控制時先確認遠端登入與提交身分，未登入就先顯示登入頁，透過 Git 認證管理員的視窗或瀏覽器登入，CCA 不經手帳密。1.0.1-luna 新增版本控制面板：變更檔案以顏色圖示呈現（黃色修改、綠色新增、紅色不建議提交），點選要提交的檔案、提交並推送，右側是分支泳道的提交紀錄圖；提交前掃描疑似金鑰，可設定永遠不提交的檔案，遠端可定時擷取並在 AI 閒置時快轉拉取。所有 AI 額度用完而停止的任務，可依各 AI 的重置時間自動接續，等待時間、時段與次數都能設定。[操作與限制](git.md)。

1.0.1-oss 重做全部選用主題：每款都從原作取幾個可辨認的裝置（例如 Codex 的 `>_` 與泡泡訊息、Claude 的襯線回覆與星芒、NTE 的貼紙按鈕、Sky 的天空伺服器列），並新增取材自 halyosy 合唱曲的 Connecting 與 Blessing，共十三款；1.0.1-sol 再加上 CCA 自製的 2026 萬聖節（亮、暗）與追獵行動，共十六款。[設計與來源](themes.md)。軟體更新改為兩個來源：遠端發行站（未啟用）與自動建立的本機資料夾；放入較新的安裝包後，閒置時自動更新並重新開啟。[操作與復原](workbench.md)。Gemini 有了私訊，也能加入一般群組擔任第三位審查者；帳號檢查會辨識 Google 已停止支援的個人帳號，不再顯示「額度未知」。群組或多代理流程中額度不足的 AI 標示「跳過」並交給下一位，全部用完時強制停止並記錄做到哪一步，額度恢復後可接續。[操作與限制](gemini.md)。

1.0.1- 補齊 Gemini 的名稱、頭像、橫幅與性格設定。工作流程依實際節點順序顯示，支援同一後端的多個節點；桌面與 CLI 共用 Gemini 身分及中斷狀態。[操作與限制](gemini.md)。

1.0.0-sol 修正 Gemini CLI 新版打包格式的登入偵測，允許登入視窗開啟時重新檢查，並分開顯示登入、服務及額度查詢結果。[操作與限制](gemini.md)。

1.0.0-terra 修正本機檔案連結與長指令提示框；模型推薦改用任務、範圍、風險、推理、驗證與限制等因素，明確延續的需求會參照前文。資訊不明時採一般設定，可預覽依據並手動固定。[選擇規則](adaptive-routing.md)。

1.0.0-luna 新增 Gemini Google 帳號登入、方案與額度查詢，以及可修改檔案的流程審查者。[操作與限制](gemini.md)。Codex、Claude、Gemini 主題各有亮色與暗色版本。[設計與來源](themes.md)。

1.0.0-oss 新增依需求特徵自動選擇模型與思考程度，可分別保留手動控制，並記錄每輪選擇原因；不額外呼叫模型。[規則與限制](adaptive-routing.md)。同版新增 OpenAI Codex、Anthropic Claude、DeepMind Gemini、Tokyo Night、urban legend、The Sky、Infinite 七款主題，桌面可預覽後保存，CLI 沿用相同語意色。[設計與來源](themes.md)。
