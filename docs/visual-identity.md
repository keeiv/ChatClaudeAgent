# 視覺識別：協作工作終端（1.0.0）

CCA 保留 Discord 的版面（左側伺服器列、頻道清單、聊天、成員清單），因為使用者一開始就要這種熟悉感；外觀則是自己的。介面以協作工作終端為主題，用清楚的識別色、狀態與操作區分各個代理，不依賴私人角色設定。

這份文件寫給之後改介面的人和 AI。下列規則是 CCA 原生主題的預設；十五款選用主題（`ui/themes.css`）可依各自來源使用圓角、不同表面、圖樣，以及來源本身的漸層或光暈，仍須共用語意 token、隊員身份與可讀的狀態。元件本身不另造第三套配色。主題的形狀、來源與生成方式見 [介面主題](themes.md)。

## 原則

| 項目 | 做法 | 為什麼 |
| --- | --- | --- |
| 底色 | 石墨灰（`--bg-*`），不用 Discord 的灰紫色 | 和 Discord 區隔，也讓隊員的識別色更突出 |
| 主要動作 | 白色切角按鈕、深色字（`.btn.primary`） | 唯一的高亮動作，不和任何隊員的顏色搶 |
| 訊號色 | 冰藍 `--signal`：焦點框、連結、區段標記、進度、選取 | 只有一個強調色，看到藍色就知道可以操作或正在進行 |
| 隊員識別色 | Claude 橘、GPT 綠、本地審查員 1 粉、本地審查員 2 紫、使用者鋼藍（`--claude` 等） | 同一位隊員在頭像外圈、名字、流程節點、時間軸長條都是同一個顏色，不會分不清是誰在說話 |
| 形狀 | 切角板（左上與右下切一刀，`clip-path`），取代圓角 | 戰術介面的語彙，也是一眼能認出 CCA 的特徵；頭像維持圓形，人還是人 |
| 需要指揮官處理 | 左緣斜紋警示帶（核准卡、警告橫幅） | 平常不出現，出現時一眼就知道要做決定 |
| 區段標題 | 冰藍三角標記加字距（`.card-title::before`） | 像終端機的區段標籤，不用 emoji |
| 聊天區底紋 | 24px 點陣，透明度 3.5%，隨訊息捲動 | 像作戰桌的地圖格線，不干擾閱讀 |
| 伺服器列 | 切角方塊，滑過時切角變大 | 取代 Discord 的圓形變圓角方形 |

## 不做的事

- 不加漸層、玻璃擬態、發光陰影、青色霓虹。這些是常見的 AI 產品模板。
- 不新增字體；數字與路徑用 `--mono`。
- 不在切角元件上用外陰影：`clip-path` 會把它切掉。焦點框改用內框（`inset` 的 `box-shadow`）。
- 不寫死顏色；新顏色先加成 `:root` 的變數。

## 實作位置

- `ui/app.css` 開頭的 `:root`：所有顏色與 `--cut`（切角大小）。
- `ui/app.css` 的「squad console identity」段落：切角、識別色外圈、斜紋、點陣、伺服器列。
- 頻道設定面板（`opsPanel`）、互審時間軸（`timelineCard`）、審查窗格（`renderReview`）在 `ui/app.js`，樣式在 `ui/app.css` 結尾。

## 介面補完（2026-10-25）

- 登入頁、帳號面板及預設控制項也使用切角與石墨灰；白色只作主要動作。選單的選取、滑過狀態使用訊號色或深色底，不再出現白底白字。既有自訂頭像與橫幅維持使用者設定。
- 舊版樣式中的十六進位色值集中到 `:root`，流程中的紫色忙碌狀態改用訊號色。斜紋與點陣是圖樣，不當作裝飾性漸層；點陣仍為 24px、3.5%。
- 切角主要按鈕使用雙層內焦點框，避免白底上的冰藍外框被裁掉。系統的減少動態偏好套用到時間軸、輸入中與窗格動畫。
- 審查窗格加入檔案路徑篩選、方向鍵／Home／End 切換檔案、保留原始程式碼行與水平捲動。窄視窗把檔案清單放到上方。
- 逐行意見與未加入的文字草稿保存在目前 WebView2 使用者資料中的 localStorage，依對話分開；儲存不可用時明確提示。已加入的意見有總覽，只有主機確認聊天訊息已收到後才清除。
- 審查讀取與還原都帶請求識別，舊回應不能覆蓋新範圍。還原前比對該檔案和審查時的版本，若中途被修改就拒絕還原並保留內容。CLI 的 `/revert` 使用同一項保護。

驗證方式與實際結果見 [視覺補完驗證](visual-identity-validation.md)。

## 協作功能（0.8.0）

計畫、獨立意見、審查關注點與隔離工作區集中在「任務控制」，跨對話通知集中在「收件匣」。沿用切角、石墨灰、白色主要按鈕與訊號色；不另建一套配色。計畫核准與執行分開，合併前顯示目標及預演結果；所有模型輸出以文字或經跳脫的 Markdown 顯示。操作與限制見 [協作控制](collaboration.md)。

## 設計來源

群組導覽沿用 Discord「首頁／專案圖標 → 專屬側欄」的分工。CCA 首頁保留私訊及全域入口，協作群組各自佔一個固定圖標；群組圖標使用切角、自訂頭像或名稱縮寫。冰藍僅用於選取、焦點與拖曳落點，待處理數字標記放在切角外層，避免被裁掉。群組的實際對話與工具入口分區呈現，不建立無作用的假頻道；既有任務控制與交付驗證仍位於右側底部，左欄提供同一套功能的入口。操作、資料相容與來源見 [群組導覽](group-navigation.md)。

個人徽章使用獨立的 16／24 像素母版，由不公開的圖標產生器產生。七款共用實色、45 度切角及透明留白；歷代紀念款依舊 EXE 的交環、三段式 C 與銜接 C 重繪，不帶回舊圖的漸層。徽章色列於 `:root` 的 `--badge-*`，只用於身分圖形，不替代主要動作或焦點訊號色。個人卡名稱區最多展示六枚，完整收藏與調整集中在徽章目錄。來源、排序與本機授予方式見 [個人徽章](badges.md)。

1.0.0 的程式圖標、介面標誌、字標與 CLI 點陣，統一由不公開的圖標產生器的 32 單位母版產生。兩個相向的 C 在中段銜接，使用 45 度切角與單色輪廓；程式圖標增加石墨灰切角底板。介面內繼承文字顏色，不用 Claude、GPT 的識別色替代 CCA 品牌色。ICO 含 15 種原生尺寸，CLI 使用 16 欄、8 列半格字元。研究來源與製作規格見 [1.0 圖標設計](brand-1.0.md)。

設計方向是在 2026-10-25 的競品調查之後決定的（見 [competitive-research.md](competitive-research.md)）。介面上參考了這些做法，但外觀沒有沿用任何一家：

- 審查窗格的範圍切換、逐段還原與逐行意見：OpenAI Codex 桌面版的審查窗格。
- 互審時間軸：Aubia 的互審時間軸（每輪的代理、結論與修改量）。
- 把設定收進頻道設定面板、標題列只留一行摘要：Discord 本身的頻道設定做法。
