## 新功能的重點案例

- 短問答、一般修改、風險需求、長內容與短定義分類。
- 只選目錄內模型；未回報目錄、未知家族、非文字模型、隱藏項目與不相容固定程度。
- 手動模型及手動程度獨立固定；忙碌時拒絕變更，保存失敗還原，重新開啟保留設定。
- 模擬 Claude 子程序實際收到 `--model`／`--effort`；模擬 Codex app-server 實際收到每輪的 `model`／`effort`。回覆與上下文紀錄的選擇一致。
- 八款主題全介面預覽、取消、關閉、保存失敗、方向鍵／Home／End、1440×1000 與 1000×600 視窗。
- 新主題一般文字、次要文字、Claude 及 GPT 標記相對聊天底色的對比至少 4.5:1；此檢查不代表已完成所有 WCAG 項目稽核。
- 過期預覽回應不可覆蓋新輸入；預覽不送出模型需求；頻道一般設定與模型選擇分別使用正確訊息。
- CLI 主題背景、控制碼過濾、自動偏好分開保存、原因文字及真正的終端機輸入。
