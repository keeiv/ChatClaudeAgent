# Token 活動與本機性格

## Token 活動

桌面「訂閱與用量」顯示截至今天的近 365 個日期，7 列代表星期、每欄代表一週，月份標示在底部。顏色依目前選擇的統計方式分級，數值可用滑鼠停留、鍵盤聚焦或點選查看。

| 模式 | 定義 |
| --- | --- |
| 每日 | 當日記錄的輸入加輸出 token |
| 每週 | 截至該日期的近 7 個日曆日合計，並非每週一重設 |
| 累計 | 所有已保存紀錄截至該日期的合計，可包含圖表顯示範圍之前的紀錄 |

空白日期表示沒有當日紀錄，和明確記錄為零不同。累計及近 7 日值仍可由其他日期推得。資料來自 `%APPDATA%\CCA\usage.json` 或 `CCA_DATA_DIR`，按記錄時主機的本地日期分組，不會依觀看裝置的時區重新分配。

統計含 Claude、Codex、Gemini、兩個本地審查員，以及多代理流程的 API／本地後端。cached 欄位不額外加進總數。它代表 CCA 收到並保存的用量，並非供應商帳戶全部用量或帳單。

新版不再自動刪除超過 120 個日期的舊紀錄；寫入失敗保留待存狀態，正常關閉時再保存。舊版已刪除的日期不會憑空補回。突然斷電仍可能失去尚未寫入的最新紀錄。

CLI 的 `/activity daily`、`/activity weekly`、`/activity total` 讀取同一份核心統計，顯示最近 14 個日期及已保存紀錄總計；`/about` 顯示開發目的。熱力圖僅在桌面顯示。

## 性格資料

沒有本機預設檔時，五個原生代理的性格均為 `none`。既有 `settings.json` 中的名稱、自訂性格、指派及對話不會被重設；指派暫時找不到對應資料時保留 ID，不自行換成其他角色。

在「設定 → 性格庫」建立的資料仍保存在 `settings.json`。額外預設可放在資料目錄的 `persona-presets.json`，格式見 [範例](../config/persona-presets.example.json)。重新啟動時載入，程式不自動下載角色資料。設定頁可複製成自訂版本後編輯。

預設檔必須為 JSON 陣列，不超過 1 MB、128 項；ID 唯一且不可為 `none`，只接受英數字、連字號與底線，最長 80 位元組。名稱上限 96 位元組、簡介 400、稱呼 60、提示詞 12,000。`agent` 為 `claude`、`codex`、`gemini`、`local` 或 `any`，省略時為 `any`。無效檔案整份拒絕並提示，原檔案不改寫；自訂資料與預設重複 ID 時，自訂資料優先。

性格新增、刪除與指派會先確認設定保存成功；失敗時恢復原設定。角色提示只能影響表達方式，CCA 的權限與技術規範優先。

Gemini 的適用對象使用 `"agent": "gemini"`。若本機預設檔明確設定 `"assignOnFirstUse": true`，只在設定中還沒有該代理的性格欄位時套用，空白名稱才同步使用預設名稱；已選擇 `none`、既有性格及自訂名稱均保留。`any` 不接受自動指派。此選項屬於外部資料，不會使發行版內建角色。

| 設定與保存測試 | 107 項通過，含預設不指派、舊指派保留、自訂覆寫、保存失敗與重啟保存 |

測試使用隔離資料與假後端，未呼叫實際付費模型。已檢查兩個 EXE 不含原先角色名稱與作品內容。這次本機既有的四份預設另存於資料目錄，不隨原始碼或 EXE 交付。
