# CCA 圖標

1.0.2-luna 重做了全部圖標：普通版本的程式圖標、介面標誌、字標、CLI 點陣，以及四個特殊版本的產品圖標。

## 標誌

兩道相向的弧，在 32 單位的格線上圍出一個開口朝上下的環。左弧淺色，代表撰寫的一方；右弧天藍，代表交回來的審查。兩道弧之間留出間隙：工作是交過去、再交回來，不是一個封閉的圓。天藍與介面的主要動作和焦點用的是同一個訊號色。

- 圓心 (16, 16)，中線半徑 8.6，筆畫寬 4.6，圓頭。左弧 110° 到 250°，右弧 290° 到 70°（螢幕座標，0° 朝右、順時針）。
- 程式圖標加一塊圓角 7.5 的鋼藍底板（`#151C23`），四周留 1 單位。
- 淺色標誌用 `#EDF2F6` 與 `#6FB1FF`；放在淺色底上的版本用 `#0B0F13` 與 `#1F5FBF`。
- 字標是標誌加上 CCA 三個字母：兩個 C 是同一族的弧，A 是圓頭圓角的折線，筆畫寬度與標誌相同。
- 不加漸層、光暈、陰影或第三方標誌；不要拉伸、旋轉或把兩道弧換成代理的識別色。

## 特殊版本

四個特殊版本沿用同一個底板與左弧，右弧換成該版本的顏色，環內放一個符號：

| 版本 | 右弧 | 符號 |
| --- | --- | --- |
| 俳句 Haiku | 葉綠 `#6CC69A` | 三條 5‑7‑5 長度的短線 |
| 十四行詩 Sonnet | 薰衣草 `#B7B2F4` | 菱形（十四行詩的轉折） |
| 大師巨作 Opus | 玫紅 `#E5708F` | 皇冠 |
| 寓言 Fable | 金 `#E2B867` | 攤開的書 |

## 輸出

全部資產由不公開的圖標產生器輸出：

- `assets/logo/` 的 SVG 與 PNG（標誌、程式圖標、兩種字標、16 到 256 像素的各尺寸），以及 CLI 點陣的放大預覽。
- `assets/cca.ico`：15 種原生尺寸，桌面版與 CLI 的 EXE 共用。
- `ui/logo.svg`、`ui/logo.png`，以及 `ui/icons.js` 的 `logo`：介面內左弧跟隨文字顏色，右弧讀 `--signal`。
- `src/logo_art.hpp`：16 × 16 的雙色點陣，CLI 用半格字元畫成 16 欄、8 列。

同一個產生器依同一組幾何輸出 `assets/editions/<版本>/` 的 SVG、PNG 與 ICO。寓言的 EXE 以 `fable.ico` 為圖標，俳句的 APK 啟動圖示取自 `icon-256.png`。

小尺寸都是實際輸出，不用 1024 像素的圖縮放交付。
