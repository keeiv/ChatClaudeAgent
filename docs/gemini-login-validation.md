# Gemini 登入修復驗證（1.0.0-sol）

最後確認：2026-10-27。

## 已重現與修復

本機官方 npm Gemini CLI 為 0.65.0，已有 Google 登入設定與快取。舊帳號工具試圖載入不再獨立提供的 core 套件，因此得到 MODULE_NOT_FOUND，卻提示重新登入。

新版從選定安裝的實際入口追蹤 bundled ESM SDK，保留舊版分離 core 支援；不執行 CLI 主入口，不載入沒有被引用的舊區塊或其他專案套件。登入視窗開著時可以重新檢查，開始新的登入流程會使舊檢查回應失效。

登入驗證、套件相容性、服務檢查與額度結果分開處理。只有可確認的失效登入才標示需要重新登入；額度查詢失敗不取消已驗證的登入。原始 SDK 例外與 HTTP 標頭不送入介面。
