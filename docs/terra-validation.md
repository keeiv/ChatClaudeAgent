# 1.0.0-terra 驗證紀錄

日期：2026-10-26。這次修正回覆中的本機檔案連結、長指令提示框，以及任務輪廓與模型推薦。保留既有 Gemini、十一款主題和其他先前更新。

## 本次案例

- 使用原圖的 Windows／中文路徑、尖括號、空格、括號與行號格式，確認產生正常連結。行內碼不轉成連結；HTML 標籤仍跳脫。
- 檔案連結只要求主機開啟所在資料夾。原生測試以假的 EXE 確認不執行檔案；拒絕 UNC、資料流路徑、控制碼與不存在的檔案。
- 實際 Edge 檢查長 PowerShell 指令及 900 字元不含空格的指令。提示框內容不超出方框，位置保持在視窗內；1440×900、1000×600、800×500 均通過。工具沒有輸出時也能展開完整指令。
- 任務分析涵蓋繁體中文與英文、局部修改、跨檔案、全專案、正式環境、資料風險、併發、正確性證明、多項驗證與限制。
- 區分純名詞解釋、否定的重構要求、文案引文、程式碼與引用區塊。只有長度不直接升為深入模型；不清楚的需求採一般設定。
- 「繼續」可沿用前一項需求；新的獨立要求不沿用無關風險。假的 Claude 子程序確認延續後仍收到正確模型與程度，手動固定仍有效。
- 預覽因素以文字呈現，不能把模型或測試輸出的標籤注入成 HTML。
